# Aktive Aufgabe: Referenz-Heizraum in Babylon.js

Unity wird nicht verwendet. Der Gesamtplan bleibt das Ziel; es wird eine Aufgabe nach der anderen abgeschlossen.

Dieses Paket: lokale Reflexionsdaten/Licht, feinere Boden-/Wandoberflächen, Rohrmantel mit Bogen, Verschraubungen, Schrauben und direkt lesbare Reglerbeschriftung im bestehenden Haus. Kein weiteres separates Spiel.

Status: NICHT FERTIG. Lokale Syntax-/Rechendatenprüfung ist keine WebGL-Abnahme. Der CI-Test muss den echten Browser starten, C93x-Fehler-/Normalfall und konkrete 3D-Klicks prüfen. Screenshots müssen anschließend visuell beurteilt werden. Ein installierter Windows-Test ist separat nötig.

Offen bleiben herstellergetreue Innenmodelle, vollständige 3D-Abgasmessung, vollständiger Haus-/Kehrmissionen-Abgleich und Normprüfung. Dieses Paket darf nicht als vollständige Kaminkehrer-Simulation bezeichnet werden.
